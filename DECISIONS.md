# Design decisions

Three choices shaped this take-home: how we orchestrate, how we constrain the model, and what we refused to build under a tight clock.

**1. Planner-then-execute, not a supervisor.** The brief’s core is routing and chaining, then one synthesised answer with attribution. A LangGraph supervisor that “picks the next agent” looks more agentic and is a poor internal-platform default: it can loop, call Budget twice, and spend unbounded tokens. A planner extracts slots and a route (`destination → itinerary → budget`, or a subset). Conditional edges run that DAG. “3 days in Lisbon” skips Destination. Compare-only skips Itinerary and Budget. Itinerary reads Destination’s `primary` from graph state; it does not call Destination as a nested tool, so the audit log is the chain. Bounded cost, deterministic, easy to explain when something goes wrong.

**2. The model proposes; the platform enforces.** Destination must not recommend a place that breaks a hard constraint. Budget must not silently exceed the cap. Prompts alone are not a control. Agents emit Pydantic objects. Python then drops excluded cities (`not Spain`) and, if the total is over budget, forces `within_budget=false` and a cheaper alternative. OpenRouter’s free router often returns prose or a safety string instead of JSON; native structured output failed in those cases (`Invalid JSON… 'User Safety: safe'`). We ask for JSON, scrape the object, and retry once. The synthesizer is markdown on purpose: wrapping it in a schema was throwing away good traveller copy.

**3. What we cut.** No Entra/OAuth (`?role=operator` only) — identity is the live-round topic. No live prices, maps, extra agents, or RAG; general knowledge is enough for the MVP. SQLite with `requests` / `agent_runs` instead of Postgres: the schema is the requirement, not HA. SSE of agent start/finish instead of token streaming, because transparency of *which specialist ran* matters more than token drip. Visual work stopped at readable markdown. Better a working graph and an honest audit trail than six shallow agents.
